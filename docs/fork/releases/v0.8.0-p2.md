# PdfCraft 0.8.0-p2

## What changed

- Help > Check for updates now installs the new version itself: Install and relaunch downloads it, checks it against the release's SHA-256 checksums and its signature, replaces the app in Applications and reopens it. If anything fails, an alert says why and the installed version opens again.
- PdfCraft checks for a newer release once at launch, quietly: the Updates dialog appears only when there is one.
- The update check no longer uses GitHub's rate-limited API, so it keeps working on shared networks such as a campus or office.
- A one-line installer (`curl -fsSL https://raw.githubusercontent.com/krichelj/pdfcraft/main/packaging/macos/install.sh | bash`) installs or updates PdfCraft without macOS's "Apple could not verify" block.
- The new update messages are translated into all 22 interface languages.
