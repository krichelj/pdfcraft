# PdfCraft 0.9.0-p3

## What changed

- Brings in 157 upstream storytold/pdfcraft commits, up to [`ec0a965074f3`](https://github.com/storytold/pdfcraft/commit/ec0a965074f376a5bf610435948e4e5184bf3299):
  - M5.6: preserve nested annotation values in FDF exports (#1971)
  - Edit text: refuse a rewrite of text that is a clipping path (#3447)
  - Add fills and border widths to text boxes and callouts (#3366)
  - Tests: the parser-cancel test guards against a hang, not a 2 s limit (#1970) (#3462)
  - docs: base the XFA page area Acrobat observations on a synthetic form (#2574) (#3431)
  - M10: Office export follows forms 50 deep and up to 50 000 a page and says where it stops (#3120) (#3426)
  - M3: keep save shortcuts behind other dialogs (#3387)
  - M2: fix shading bounds in Type 3 glyphs (#3178) (#3412)
  - Never-crash gate on the oracle and testkit crates; oracle find() no longer panics on an empty needle (#3435)
  - M6: a date typed without separators fills a yyyymmdd field (#3388)
  - M6: the date picker follows a whole date typed while it is open (#3393)
  - M6: a secured form's notice bar still says it is a form (#3404)
  - Text: tracked glyphs retain their word boundaries (#3477)
  - Docs: install the CLI and register it with MCP clients (#3478)
  - M2: a JP2 image in a colour space the decoder refuses is drawn by its component count (#3306) (#3363)
  - fix(parse): accept spaces between stream and its line break (#3378)
  - M2: a tiling pattern drawn once shows its cell at full scale (#3349) (#3356)
  - fix(sign): offer only certificates that may sign documents from the Windows store (#3365)
  - fix(windows): name the single-instance socket by the session id, so a launch without SESSIONNAME finds its session's window (#3338) (#3340)
  - Keep long menus usable in short windows (#3374)
  - fix(preflight): identify PDF standards by XML namespace (#3364)
  - Clear image pixels intersected by redaction marks (#3368)
  - Keep document scroll position across viewer modes (#3362)
  - Clamp the zoom-anchor scroll to the content so zooming out no longer jolts the page (#3266) (#3350)
  - Fix clock-dependent form properties test (#3367)
  - M8: document discard-on-error for public redaction calls (#3302)
  - M3: Accelerate coarse wheel scrolling (#1094)
  - M2: a fax image with fewer /Rows than its /Height is decoded to its height (#3308) (#3316)
  - M1: a saved file keeps its creation date (#2658) (#3291)
  - Find and edit images whose Do or cm spans two content streams (#3294)
  - Read /ActualText from named property lists in edit text and export (#3301)
  - M7: work out each font's space width once per paragraph rewrite (#2616) (#3297)
  - fix(ui): the recovery folder is owner-only on Unix (#3320)
  - docs: vendor/README keeps one hayro-interpret row, with the patches lost to number collisions (#3312)
  - Read doubled-sign integers like --280 in the COS lexer (#3299)
  - M10: exported TIFF and JPEG pages record the resolution they were drawn at (#3332)
  - cli: info names the standard a document declares (#3328)
  - Render weekday letters in FormCalc date pictures (#3321)
  - Drop U+FFFE and U+FFFF from XFDF/XML form-data export (#3330)
  - ci(deps): bump cachix/install-nix-action (#3322)
  - and 117 more
