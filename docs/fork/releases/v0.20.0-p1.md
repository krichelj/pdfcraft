# PdfCraft 0.20.0-p1

## What changed

- Brings in PdfCraft 0.20.0 from the original repository (storytold/pdfcraft, 870 commits): among them split view (two panes, one document or two), cloudy comment shapes, per-reviewer review statuses, custom paper sizes in Page Setup, text in replaced lines keeping its font, and many XFA form, optimizer and accessibility-tag fixes.
- Help ▸ Check for updates keeps the fork's flow: it installs the fork's releases and offers Merge and update when the original PdfCraft is ahead. Upstream's new built-in updater (craft-update) would install the original over the fork, so it is not used.
- The merge conflicts were resolved by hand (issue #89).
