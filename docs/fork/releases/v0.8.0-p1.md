# PdfCraft 0.8.0-p1

## What changed

- The first published release of the krichelj/pdfcraft fork: PdfCraft 0.8.0 from storytold/pdfcraft, for macOS on Apple silicon (M1 and later) only, numbered `<upstream version>-p<N>`.
- Ships as a drag-to-Applications DMG (and a zip of the app) for Apple silicon, cross-built on the fork's own Linux runners.
- Help > Check for updates asks this fork's releases, not upstream's, and counts `-p<N>` patchlevels as newer versions.
- The app is ad-hoc signed, not notarized by Apple, so macOS blocks a copy downloaded in a browser until you choose Open Anyway in System Settings > Privacy & Security.
